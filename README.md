# Lanka Wear

Clothing storefront + admin for a Colombo brand. Next.js 16, Tailwind 4, MySQL. Payments: cash on delivery and bank transfer.

Dev: create a MySQL db, import `mysql/schema.sql` (+ `mysql/seed.sql`), copy `.env.example` to `.env.local`, `npm run dev`.
Deploy to LankaHost: see `DEPLOY-LANKAHOST.md`.
